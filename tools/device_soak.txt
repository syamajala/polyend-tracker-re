# Device soak (issue #23): one round of screen hopping on a real Tracker, safe on
# a loaded project: nothing is entered, saved, loaded or deleted (no pads, no
# encoder on Config / Master, no confirm keys). It plays the loaded pattern;
# start it stopped (each round checks).
# Config > USB > Remote control on, then repeat the round and check the log:
#
#   tools/tracker_remote.py /dev/ttyACM0 $(yes tools/device_soak.txt | head -12) --log soak.log
#   tools/telemetry_check.py log soak.log      # stack free, render, loop limits
#   grep -a -e lockup -e FAULT -e STUCK soak.log
#
# A stack overflow into the guard resets the Tracker; the next boot logs
# "reset reason: core lockup". Open Recent (the deepest frame, 6,032 B) loads a
# project, so it is not part of the round: open one by hand if that is fine.
