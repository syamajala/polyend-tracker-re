# Device stack paths (upstream #16): the deep or busy paths in one run, for
# the telemetry stack watermark on a real Tracker. Start stopped, on a
# project whose instrument 1 is a sample and whose pattern 1 plays.
# Config > USB > Remote control on, then:
#
#   tools/tracker_remote.py /dev/ttyACM0 tools/device_stack_paths.txt --stop-on-fail --log paths.log
#   tools/telemetry_check.py log paths.log     # stack free (the loop / CPU lines flag the editor stalls)
#   grep -a "stack peak" paths.log | tail -1
#   grep -a -e lockup -e FAULT -e STUCK paths.log
#
# Card writes: a resample take into a new instrument and the editor's undo
# stay in the unsaved project; Export Samples writes Export/<project>/; the
# last step reopens the project from the card (Don't Save), so the run's
# changes are dropped. The Sample Editor effects block the main loop while
# they run (soft-float double, Timestretch beat about a minute on a short
# sample), so the waits are long. Module import: tools/remote_scripts/module_import.txt.
# Deepest static frames (-fstack-usage): Open Recent 6,032 B, file lists
# 5,024 B, Export Samples 4,824 B. Measured 2026-10-24: ~12.2 KB for every
# path except Open Recent while the current project is saved on the card
# (startOpenRecent -> startOpenProject -> recentsLeaveCurrent, two Recents
# lists on the stack): 18,228 B. The last step below is that path when the
# project at the start was a saved one.
wait 300
tap PATTERN
wait 300
if play == 1 tap PLAY
wait 500
expect-stopped

# Playing: screens, the firmware list, a resample of the mix.
tap PLAY
wait 2000
tap PERFORMANCE
wait 1000
tap MASTER
wait 1000
tap CONFIG
wait 300
tap LEFT; tap UP; tap UP; tap UP; tap UP; tap UP; tap UP; tap UP; tap UP
tap DOWN; tap DOWN; tap DOWN; tap DOWN; tap DOWN    # Firmware
tap RIGHT
tap F8               # Firmware update: the list
wait 1200
expect-text Firmware
tap F7               # Cancel
wait 300
tap PATTERN
wait 300
tap SAMPLERECORDER   # "This will stop the pattern": Resample (F6) keeps it playing
wait 800
tap F6
wait 800
expect-screen Resample
tap F8               # arm (starts on the next bar)
wait 6000
tap F8               # stop at the next bar
wait 6000
tap PATTERN
wait 300
# Screenshots and display frames over USB while playing.
screenshot paths1.png; frame paths1.otf; screenshot paths2.png; frame paths2.otf
screenshot paths3.png; frame paths3.otf; screenshot paths4.png; frame paths4.otf
screenshot paths5.png; frame paths5.otf
if play == 1 tap PLAY
wait 500
if play == 1 tap PLAY
wait 500
expect-stopped
